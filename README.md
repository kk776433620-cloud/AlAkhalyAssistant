# مشروع المساعد الذكي - الأكحلي (Al-Akhaly Voice Assistant)

هذا الملف المضغوط يحتوي على جميع المكونات البرمجية الأساسية الجاهزة للتطوير على أندرويد ستوديو (Android Studio).

## محتويات المشروع:
1. `AndroidManifest.xml`: الأذونات والخدمات.
2. `AlAkhalyAccessibilityService.kt`: خدمة إمكانية الوصول وتجاوز الإعلانات.
3. `AlAkhalyPersona.kt`: شخصية التطبيق واللهجة اليمنية الأصيلة.
4. `AlAkhalySelfDeveloper.kt`: نظام التطوير الذاتي وإنشاء السكريبتات.
5. `AlAkhalyCodeExecutor.kt`: محرك تنفيذ الأوامر المحلية.
6. `LocalBrainDatabase.kt`: ذاكرة التطبيق والقواعد المحلية عبر Room Database.
7. `AlAkhalyService.kt`: الخدمة الخلفية والنافذة العائمة.
8. `MainActivity.kt` & Layouts: الشاشات والتصميم.
